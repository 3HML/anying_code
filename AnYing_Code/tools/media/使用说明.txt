安映 · 音频素材准备

环境：Python 3.8～3.12；使用标准库audioop和wave，无需额外Python包。
Python 3.13及以上不附带audioop，此脚本请使用兼容版本运行。
命令：python prepare_music.py input.wav output_dir
输入：未压缩整数PCM WAV，单/双声道，8/16/24/32 bit；不直接读取MP3或加密音频文件。
输出：output_dir/MUSIC.WAV，48000 Hz、16 bit、单声道PCM。已有同名输出不会覆盖。

最多32首音乐：每首分别输出到独立目录，将结果改为TRACK01.WAV～TRACK32.WAV等不同英文短文件名，再复制到FAT32卡根目录。
实际播放按FAT目录条目顺序；文件名编号用于整理，不代表系统一定按名称排序。
图片为24位未压缩BMP，正高度、4:3，640×480～1280×960，同样放在TF卡根目录。
脚本只创建输出文件，不格式化存储卡、不写裸扇区、不修改原音频。
本代码包随附TF_Card目录中的演示图片与音乐；技术报告和演示视频分别提交。

安映 · 红外接线与遥控操作

一、J1扩展接口连接
模块 VCC  → 开发板 J1第29脚（3.3 V）
模块 GND  → 开发板 J1第30脚（GND）
模块 OUT / DAT / S → 开发板 J1第1脚（GPIOA_0，FPGA D14，ir_rx）
按模块引脚丝印和开发板J1编号确认连接，不用“从左数第几脚”代替引脚编号。
J1第11脚为5 V，本作品不使用该脚供电。接收信号为低电平有效，空闲为高。

二、处理分工
接收模块完成红外接收与载波解调，输出脉冲信号；FPGA完成输入同步、滤波、脉宽判断、NEC帧检查及动作分派。
逻辑源码：src/user_source/hdl_source/ir_nec_remote_100.v
端口/引脚：top_tf_hdmi_audio.v中的ir_rx，constraints_source/pin.adc中的D14/LVCMOS33。
有效帧按00/FF用户码及命令反码校验；标准短重复帧不产生新的操作，未分配按键不触发动作。

三、实际20键遥控器
Power：睡眠/唤醒。睡眠时其他遥控键不动作，板上四个按键也可以唤醒。
Menu：进入/退出参数页。
Test / 0：亮度增加/降低；+ / -：音量增加/降低。
Return：普通图片浏览中切换自动/手动。
左方向键：手动浏览进入缩略图；在缩略图中再次按下，打开选中的图片并退出。
右方向键：普通手动浏览中的下一张。
播放键：背景音乐开关；C：下一首歌曲。
数字1 / 2：缩略图中左右/上下切换选择。
数字3：普通自动浏览中调整轮播周期，1～30秒循环；其余数字4～9未分配功能。

四、交互规则
参数页内遥控亮度、音量快捷调节直接保留，退出不会撤销；操作时自动选中对应参数。
下一首自动选中歌曲栏；音乐开关不改变当前选中项。
模式切换和下一张仅在普通浏览中生效，下一张还要求手动模式。
遥控操作不触发普通浏览页的本地按键引导。

对比度由板上参数页调节，未设置遥控对比度快捷键。

# 安映——基于国产FPGA的交互式多媒体展示终端

队伍编号：49962

安映在单块安路FPGA开发板上完成图片显示、音乐播放与交互控制，可用于个人桌面、展览和多媒体展示。工程提供可编译源码、位流、串口工具、使用资料以及TF卡演示素材。

## 功能

- 图片自动轮播、手动切换、淡入淡出、八档缩放和缩略图选图。
- 支持640×480～1280×960的4:3、24位未压缩BMP，采用四图滚动缓存。
- 支持最多32首48kHz、16bit、单声道PCM WAV，提供24频带音频可视化。
- 亮度、五档对比度、音量、轮播周期与定时设置；已保存参数掉电保留。
- 板上按键/开关、UART状态查询与控制、NEC红外遥控。
- 低功耗睡眠与按键/遥控唤醒。

## 快速开始

1. 下载或克隆本仓库，保留目录结构，建议放在较短的英文路径。
2. 使用安路Tang Dynasty **6.2.190657**打开`AnYing_Code/src/td_project/lab_ex5_i2s_v1.0.al`。目标器件为**EG4S20BG256**，顶层为`top`。
3. 可执行综合、布局布线和位流生成，也可直接下载`AnYing_Code/bit/AnYing.bit`。
4. 将`TF_Card`内的BMP和WAV文件复制到**FAT32卡根目录**。板卡断电后插卡，连接HDMI B和5V电源，再上电。
5. 串口操作运行`AnYing_Code/tools/uart/Open_Serial_Control.cmd`，选择CH340端口，通信参数为115200/8N1。
